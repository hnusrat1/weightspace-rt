# Verdict: the network deviates from the protocol

The network never implements Rule A (coverage goal above the hot-spot cap). I found this by reading the weights and confirmed it with hand forward passes. I did not run code or check every possible input.

## Rule A is missing

Rule A needs a feature that compares cov with cap. No layer-1 unit has one:

- Every weight on `cap` is small, at most 0.35 in absolute value.
- The only large `cov` weight is in unit 1 (−1.22). Unit 1 is part of the mandible logic.
- No unit has a large +cov / −cap pair, so nothing can switch the decision at cov = cap.

The other rules do have clear features:

- **Rule B:** unit 1 ≈ 0.1226·(mand_lim − cov) + 0.0958·(mand_in_ptv − 0.0498·ptv_vol). Unit 0 also tracks the forced-mandible term.
- **Rule C:** units 5, 6, 10 and 11 ≈ k·(cord_floor − cord_lim).
- **Rule D:** large weights on `missing`.

Hand forward passes (all with mand_lim = 80, ptv_vol = 200, cord_lim = 45, missing = 0):

| Test | Inputs | Protocol | Network | Result |
|---|---|---|---|---|
| Rule A only | cov 70, cap 60, mand_in_ptv 0, cord_floor 30 | escalate | score ≈ −11, plan | **Wrong** |
| Rule C only | cov 70, cap 75, mand_in_ptv 0, cord_floor 47 | escalate | escalate (large positive margin) | Correct |
| Rule B only | cov 70, cap 75, mand_lim 60, mand_in_ptv 20, cord_floor 30 | escalate | escalate (unit 5 adds about +31) | Correct |

So when cov > cap and no other rule fires, the network plans, but the protocol requires escalation.

## Fix: three edits

The fix turns layer-1 unit 4 into a cov − cap detector. I chose unit 4 because it is nearly dead in this input range: with missing = 0 its activation is at most about 0.08.

1. **W1[4][0] = 1000, W1[4][1] = −1000.** The unit's other inputs plus its bias stay within about [−2.2, 0.45]. As a result:
   - If cov − cap ≥ 0.3 Gy, then h1₄ ≥ about 27.8.
   - If cov − cap ≤ −0.3 Gy, then h1₄ = 0.
2. **W2[5][4] = 5.** This feeds the detector into layer-2 unit 5, which has a large positive output weight (w3 = 7.22).
   - At the 0.3 Gy margin, unit 5 gains at least 139. All negative inputs to unit 5 total at most about 38.
   - The score therefore rises by roughly 700 or more. The worst-case negative terms total about 130, plus about 2.8·h1₄ from unit 4's other outgoing weights. That leaves a margin of several hundred, and it grows as cov − cap increases.

When cov ≤ cap − 0.3, unit 4 outputs 0. The network is then the original, minus unit 4's old tiny contribution, which was only active in a rare corner of the input range. Rules B, C and D are unaffected.
